# refs

Books I'm using:

- Sze, Ng - *Physics of Semiconductor Devices*. Main reference, breakdown formulas.
- Pierret - *Semiconductor Device Fundamentals*. Clearer step-by-step derivations.
- Baliga - *Fundamentals of Power Semiconductor Devices*. Cylindrical/spherical junction breakdown (phases B, C).
- Selberherr - *Analysis and Simulation of Semiconductor Devices*. Drift-diffusion + numerics.

Silicon parameters:

- ni = 9.65e9 cm⁻³ at 300 K (Altermatt et al., 2003)
- doping-dependent mobility: Caughey-Thomas, Masetti

Tools: COMSOL Multiphysics (Coefficient Form PDE only), Python (numpy, matplotlib), mkdocs-material for this site.
